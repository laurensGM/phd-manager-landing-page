# PhD Manager — Landing Page

Marketing site for **PhD Manager**, a research tool for PhD students in theory-driven fields.

## What PhD Manager is

PhD Manager helps doctoral students turn literature highlights into structured claims, so the literature review becomes the start of an argument instead of a pile of notes to re-read later.

Core ideas:

- **Capture snippets** from papers (via browser extension) linked to constructs, models, and sources
- **Search and filter** evidence by paper, construct, model, or type
- **Build claims** from snippets before writing full paragraphs
- **Collaborate with supervisors** on models, tasks, and progress in one shared space
- **Listen offline** to AI-narrated audio summaries of papers

The product is piloting with PhD students and supervisors at Stellenbosch Business School.
